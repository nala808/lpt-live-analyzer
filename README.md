# 🔬 LPT Live Analyzer

A real-time computer vision system for detecting surface defects using Liquid Penetrant Testing (LPT).

---

## 📌 Overview

This project analyzes surface defects using image processing techniques.
It supports live camera input and image upload for real-time detection.

---

## ⚙️ Features

* Live camera streaming
* Image upload analysis
* Real-time defect detection
* Crack and porosity classification
* Accept / Reject decision system

---

## 🛠️ Technologies

* Python
* Flask
* OpenCV
* NumPy

---

## 🚀 How to Run

pip install -r requirements.txt
python app.py

Then open:
http://127.0.0.1:5000

---

## 🎯 Purpose

Demonstrates computer vision applications in industrial inspection.
